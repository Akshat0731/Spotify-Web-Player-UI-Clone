# 🎵 Spotify Web Player UI Clone

A Spotify-inspired web player interface built using **HTML and CSS**. This project was created to practice CSS layouts, Flexbox, responsive design, positioning, hover effects, and UI styling.

## ✨ Features

- 🎧 Spotify-inspired dark theme
- 🏠 Sidebar with Home, Search and Your Library
- 🎵 Playlist and Podcast sections
- 🔥 Recently Played section
- 📈 Trending Music section
- 📊 Featured Charts section
- 🎶 Music player with playback controls
- 📱 Responsive layout for smaller screens
- ✨ Hover effects and styled UI components
- 🔤 Montserrat font integration
- 🎨 Font Awesome icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome
- Google Fonts

## 📚 What I Practiced

- CSS Flexbox
- Sticky positioning
- Fixed positioning
- Responsive design using Media Queries
- Cards and layouts
- Hover effects
- Custom range/progress bar
- Sidebar and navigation design
- Building a real-world website UI from scratch
